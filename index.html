⏳ Initialisation…
💡 Config permanente : après connexion, un fichier HTML mis à jour est automatiquement téléchargé avec la config Firebase intégrée. Remplacez votre ancien fichier par ce nouveau — il fonctionnera sur n'importe quel navigateur sans reconfiguration. Vous pouvez aussi le télécharger manuellement avec le bouton ci-dessus.
Règles Firestore sécurisées (à copier dans la console)
rules_version = '2'; service cloud.firestore { match /databases/{db}/documents { match /eleves/{id} { allow read, write: if request.auth != null; } match /paiements/{id} { allow read, write: if request.auth != null; } match /config/{id} { allow read, write: if request.auth != null; } match /frais/{id} { allow read, write: if request.auth != null; } match /roles/{uid} { allow read: if request.auth != null; allow write: if request.auth != null && get(/databases/$(db)/documents/roles/$(request.auth.uid)).data.role == 'admin'; } } }
N'utilisez PAS le mode test (lecture/écriture libre) en production.

Gestion des Comptes
Comptes gérés via Firebase Authentication
Modifier un mot de passe (Admin)
Seul l'administrateur peut modifier les mots de passe.

Pour modifier le mot de passe d'un autre compte, utilisez la Console Firebase → Authentication → Users → ⋮ → Reset password.

Pour créer/supprimer des comptes : Console Firebase → Authentication → Users.

Pour définir le rôle admin : Firestore → roles/{uid} → {role: "admin"}.
